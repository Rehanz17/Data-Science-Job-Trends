# Project Overview  
This project focuses on analyzing global job trends within the data science field, using publicly available datasets. The aim is to explore salary patterns, job categories, work environments, and other critical factors that influence compensation across the data science job market.

This analysis will provide valuable insights for current and aspiring data professionals, helping them understand trends in job roles, compensation, and the increasing prevalence of remote work opportunities.

## Introduction  
With the growing emphasis on data-driven solutions, the field of data science has seen a surge in job opportunities. This project seeks to explore:

- Salary trends across various job roles (e.g., Data Scientists, Data Engineers, Machine Learning Engineers)
- Geographic variations in pay
- The impact of work settings (remote, in-person, hybrid), company size, and experience levels on salaries
- Employee purchasing power across regions

By addressing these questions, we aim to help professionals make data-driven career decisions, better understand the market, and identify lucrative job opportunities.

## Dataset Information  
- **Source**: Kaggle  
- **Dataset Format**: CSV file with 12 columns and 9,355 rows  
- **Time Frame**: 2020-2023

### Key columns include:
- **work_year**: Year the data was recorded  
- **job_title**: Job role title (e.g., Data Scientist, ML Engineer)  
- **job_category**: Broader category for analysis (e.g., Data Science, ML/AI)  
- **salary_in_usd**: Salary converted to USD for comparison  
- **experience_level**: Level of experience (Entry, Mid, Senior, Executive)  
- **work_setting**: Work environment (Remote, In-person, Hybrid)  
- **company_location**: Country where the company operates  
- **company_size**: Organization size (Small, Medium, Large)  

## Key Analyses and Questions  
This project aims to answer the following:

- How have Data Science salaries evolved year-over-year?
- Which job categories offer the highest salaries?
- What factors influence salary variations within data science roles?
- How has remote work affected compensation trends post-2020?
- How does the purchasing power of data science professionals differ across regions?

The analysis will include visualizations, statistical summaries, and geographical mappings to illustrate these trends.

## Technologies Used  
- **Programming Language**: Python  
- **Development Environment**: Jupyter Notebook  
- **Libraries**:  
  - `pandas` for data manipulation  
  - `numpy` for numerical analysis  
  - `matplotlib` and `seaborn` for data visualization  
  - `plotly` for interactive charts  
  - `geopandas` and `folium` for geographic mapping  

## Results and Insights  
Some of the key findings from the analysis include:

- **Salary Growth**: Data science salaries have consistently increased, with Data Engineers and Machine Learning Engineers leading the pack.  
- **Remote Work Surge**: Post-2020, there has been a noticeable shift towards remote work, especially in the data science sector.  
- **Geographic Pay Differences**: Salaries fluctuate significantly across regions, with variations in purchasing power due to local economic conditions.  
- **Experience-Level Impact**: Senior-level roles come with considerably higher pay compared to entry-level positions.

## Future Scope
